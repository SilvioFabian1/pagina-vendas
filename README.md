# Manual Financeiro MF

Página de vendas estática para as planilhas de precificação de produtos e serviços.

## Desenvolvimento local

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP local, por exemplo `python -m http.server 8000`.

## Publicação na Vercel

Importe este repositório na Vercel. Use **Other** como framework e deixe o diretório de saída vazio. O arquivo `index.html` na raiz será servido automaticamente. Não há etapa de build.
